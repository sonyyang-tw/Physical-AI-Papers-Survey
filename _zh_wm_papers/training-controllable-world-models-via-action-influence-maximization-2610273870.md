### Abstract

以成功、目標導向示範訓練而成的動作條件式影片生成式模型,往往會忽略所下達的動作指令,無論實際要求為何都生成一個看似合理、近乎專家水準的未來畫面。作者將此失效追溯至訓練資料缺乏足夠的「動作影響力」(action influence)。論文分析此一指標,並證明它是任何以該資料訓練出的模型所能表現出的動作影響力的上界——專家示範由於動作分佈狹窄,使下一狀態的預測無需真正關注所下達的動作即可完成,這為任何模型容量都無法突破的可控性設下了一個低上限,要提高這個上限,必須收集不同性質的資料。作者提出 Action Influence Maximization(AIM),一套用於主動收集訓練資料以提升資料集動作影響力的演算法,並在模擬導航與操作任務上,比較 AIM 與探索啟發式方法及內在動機方法的表現與資料效率。在像素層級的操作任務中,AIM 是唯一能持續改善可控性的方法:在 3000 筆示範基礎上額外加入 500 筆主動收集的 episode,即可匹配以 30 萬筆專家 episode 訓練出的 world model 在末端執行器可控性上的表現,相當於 85 倍的資料量縮減。論文已於 2026 年 10 月 19 日發佈於 arXiv,並已確認獲 CoRL 2026 接受,作者團隊來自美國普林斯頓大學(Princeton University)與哥倫比亞大學(Columbia University),成員包含 Dhruv Shah、Benjamin Eysenbach、Jaime Fernández Fisac 等研究者。

### Method

- **要解決的問題**:動作條件式 world model 承諾能預測機器人在給定狀態下採取不同動作時會發生什麼,從而在新問題上實現 policy 改進。然而當以分佈外動作查詢時,以專家示範訓練出的模型要嘛預測專家式的未來,要嘛對不合理的替代結果產生幻覺。這種「可控性失效」(模型能否忠實預測改變動作如何影響結果的能力)限制了 world model 對改進機器人 policy 的實用性。擴大訓練資料的數量與多樣性雖可緩解此問題,卻受限於收集機器人資料的成本。作者提出的核心問題是:如何從每一次真實機器人互動中,獲取對 world model 訓練最有價值的資料?相較於「如何改進 policy」這一已被廣泛研究的問題,「如何為 world model 收集最優資料」相對未被充分探索。論文提出兩項關鍵假設並加以驗證:資料收集分佈是否強烈影響下游 world model 的可控性與保真度?若確實如此,是否能直接優化資料收集分佈以改善這兩項指標?

- **Main method**:作者首先以貝氏法則與 KL 散度非負性,推導出一個理論結果(Theorem 3.1):資料集的條件互資訊(conditional mutual information)可作為任何以該資料訓練出的 world model 所能表現的「已解釋動作資訊量」的上界。這意味著 world model 的能力上限,在訓練任何模型之前,就已經可以從資料集本身的性質分析出來——當此上界夠緊時,world model 的可控性便可直接透過優化對應的條件互資訊最大化這一情境式 bandit(contextual bandit)問題來提升。基於此洞見,作者提出 Action Influence Maximization(AIM),一套主動資料收集演算法,使用一個資料導出的內在獎勵(intrinsic reward),結合「動作資訊性轉變」(比較當前策略分佈與過去行為分佈下,給定狀態轉移時動作的可能性差異)與「參考狀態覆蓋率」兩項,聚焦資料收集於那些目前資料集解釋得最差的狀態-動作配對上,形成一種具身主動學習(embodied active learning)形式。實務上,AIM 透過資料密度估計來估計並優化此一可追蹤的逐點獎勵估計器,並以批次線上(batch online)強化學習的方式迭代更新資料收集 policy 與獎勵模型。

- **和以往方式的差異**:既有提升 world model 能力的主流做法是單純擴大被動資料收集的規模與多樣性(如擴大人類遙操作示範或被動影片資料量),但論文指出,專家示範由於其動作分佈狹窄、成功對動作變異高度敏感,使得下一狀態的預測可以在不真正關注動作指令的情況下完成,world model 因此可以理性地忽略動作影響力、僅預測近乎專家水準的結果,這是單純擴大被動資料規模無法突破的結構性上限。AIM 的差異在於,它並非被動擴增資料量,而是將「資料集條件互資訊上界模型可解釋動作資訊量」這一理論關係轉化為一個可操作的主動資料收集目標,精準鎖定那些能揭露「改變動作如何改變結果」這類資訊、而非僅重複專家已展示過的軌跡的狀態-動作配對。

### Result

- **主要增強部分**:論文首先在模擬導航(Four Rooms)與像素層級機器人操作(Push-T)任務上,實證驗證資料集互資訊與下游 world model 可控性之間的理論關聯確實成立,並顯示單純擴大被動資料收集規模雖能改善不同評測分佈下的可控性,但最有效率的收集策略會因評測分佈而異——這說明被動擴增資料的效益存在結構性侷限。在像素層級操作任務的核心實驗中,AIM 達成高達 85 倍的資料效率提升:僅需在 3000 筆專家示範基礎上額外收集 500 筆主動收集的 episode,即可匹配以 30 萬筆專家 episode 訓練出的 world model 在末端執行器可控性上的表現。

- **結果是否公正**:論文將 AIM 與探索啟發式方法及內在動機(intrinsic-motivation)方法在模擬導航與操作任務上進行系統性比較,並透過消融研究(如 no-reestimation ablation)檢驗獎勵模型重新估計頻率對效能的影響,顯示較少的更新次數或許已足夠,提供了對演算法各環節效用的具體拆解而非僅報告單一端到端數字。論文也在附錄中提供完整的理論證明(Theorem 3.1 及相關引理)作為核心主張的嚴謹支撐。

### Limitation

- **已知 limitation**:論文明確指出,AIM 的一項關鍵限制是重新訓練多個學習式密度獎勵模型所帶來的實作複雜度與運算強度,no-reestimation 消融實驗顯示較少的更新次數或許已足夠,且該學習式獎勵亦可離線用於資料集過濾。要將 AIM 類方法擴展至預訓練規模,仍需更簡潔、更有效率的實作方式。此外,論文所採用的序列式強化學習近似方法,並不保證能在 AIM 情境式 bandit 問題上達成改進,這意味著在更複雜、強化學習優化本身更具挑戰性的情境下,可能需要進一步的理論工作來彌合此一侷限。

- **從 result 來看的弱項**:論文的分析並未處理後訓練(post-training)對改善資料效率的影響,而後訓練或許能讓模型從互動資料中未直接出現的動作後果進行推論。此外,論文本身定位為「主動資料收集在機器人模擬環境中的概念驗證」,將此方法遷移至通用型模型的持續改進,仍有待未來工作證明其有效性與可擴展性。

### Related work

- AIM 與本頁「Robot-Specific Action-Conditioned World Models」主題下已收錄的多篇論文(如 DepthWorld、WorldSync)同屬「提升 world model 對動作/物理狀態忠實度」這一方向,但切入點不同:DepthWorld 透過注入幾何監督解決 3D 一致性問題,WorldSync 透過診斷與對齊非專家動作下的失效模式,而 AIM 則從資料收集策略本身的理論性質切入,為「world model 能力受限於資料而非模型容量」這一假說提供了可操作的解方。
- 論文與本頁「World Models Evaluation & Physical-Reasoning Benchmarks」主題下強調系統性診斷 world model 失效模式的研究精神相通,但 AIM 更進一步,不僅診斷問題(專家資料的低互資訊上限),更提出一套可直接優化資料收集分佈的主動學習演算法作為解方。
- 判斷值得 survey 的程度:高。AIM 已確認獲 CoRL 2026 接受,提出了具嚴謹理論支撐(條件互資訊上界)且經高倍率資料效率實證驗證(85 倍)的新穎資料收集範式,對於理解「world model 能力瓶頸究竟源自資料還是模型容量」這一根本性問題提供了清晰的理論框架與可操作的解方,對後續 world model 資料工程研究具有啟發性。

### Conclusion

- **綜合評價**:AIM 提出一個新穎的理論視角,將動作條件式 world model 的品質與其訓練資料的「動作影響力」直接掛鉤——world model 的能力主要受限於資料所解釋的動作後果範疇,而非資料規模本身。透過 Action Influence Maximization 這一具理論基礎的批次線上強化學習演算法,主動引導資料收集 policy 探索那些預期具有可預測後果、卻未被既有資料集解釋的狀態-動作配對,論文證明高維像素層級機器人環境中的資料聚焦主動探索不僅可行,更帶來高達 85 倍的資料規模化效率提升。
- **與其他重要文章的關係**:AIM 可與本頁「World Models as Data Engines / Simulators for Robot Learning」主題下強調以合成或擴增資料改善 world model 訓練效率的研究互補對照——後者多聚焦於資料的生成或擴增方式,AIM 則提供了一套理論驅動的框架,用以判斷「在既有資料基礎上,下一步該主動收集哪些資料」。ROCm/AMD 在此領域尚待補強之處:AIM 的核心運算瓶頸在於反覆訓練學習式密度獎勵模型並進行逐點獎勵估計,這類頻繁重新訓練小型輔助模型並與批次線上 RL 資料收集迴圈交錯執行的工作負載模式,對訓練框架的動態圖建構、快速模型切換與小批次推論效能提出要求;隨著主動資料收集逐漸成為提升 world model 資料效率的重要手段,驗證此類「訓練-收集」交錯迴圈在 ROCm 軟體棧上的排程與效能表現,是值得關注的生態系拓展方向。
