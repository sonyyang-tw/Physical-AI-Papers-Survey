### Abstract

離散動作 token 的 VLA 模型(將動作視為與語言共享同一詞彙表的 token)在控制自由度較少的機械臂操作任務上已證實有效,但人形機器人的全身動作空間——腿、軀幹、手臂、手——維度遠高且異質性更強,直接沿用機械臂的做法會同時在 tokenization、訓練、即時推論三個環節上遇到瓶頸:單一扁平詞彙表要嘛粒度太粗、要嘛詞彙表過大;沒有任何單一資料集涵蓋全部自由度,模型必須從遙操作、第一人稱人類影片、模擬等差異極大且部分重疊的資料來源中學習;而自迴歸解碼在面對遠比機械臂更長的 token 序列時,也難以滿足即時控制的延遲要求。作者提出 Holo-M——據其所知是第一個透過擴充語言模型詞彙表來直接支援人形全身 loco-manipulation 的離散 VLA 模型。核心設計是將人形動作空間拆解為四個依身體部位劃分的 tokenizer(末端執行器、軀幹、手、運動學),使模型能同時從遙操作、第一人稱人類影片、模擬等差異極大的資料來源中學習,且不需要每個資料來源都提供全身的完整監督訊號。由於動作 token 直接併入語言模型既有詞彙表,Holo-M 避免了使用獨立連續動作專家架構所固有的「知識隔絕」問題(動作專家與 VLM 骨幹之間需要梯度隔離)。為滿足即時控制需求,Holo-M 透過分組離散擴散解碼(而非對動作 token 做自迴歸)來解碼每個身體部位的動作 token。在 SIMPLE 人形 loco-manipulation benchmark 上的大量實驗顯示,Holo-M 在 generalist 與 specialist 兩種評測設定下均取得最高成功率,且領先第二名有顯著差距。本論文由 Horizon Robotics(地平線機器人)於 2026 年 9 月 28 日發佈於 arXiv。

### Method

- **要解決的問題**:離散動作 token 化的 VLA 範式(把動作當成詞彙表中的 token,沿用語言模型的自迴歸生成機制)在機械臂操作上運作良好,因為機械臂的動作空間相對單純(腕部姿態加夾爪開合),單一 tokenizer 配合自迴歸解碼便已足夠。但人形機器人需要同時控制腿部、軀幹、手臂、手指,動作空間維度高出一個量級且各部位的物理性質、取樣頻率、資料可得性都截然不同。若直接套用機械臂的做法,會同時觸發三個複合問題:(1) tokenization 層面——用單一扁平詞彙表編碼如此異質的高維動作,會在「夠精細」與「詞彙表爆炸」之間難以取捨;(2) 訓練資料層面——沒有任何現成資料集同時涵蓋全身所有自由度的高品質標註,模型必須能從遙操作示範、第一人稱人類影片、模擬資料等彼此部分重疊卻結構迥異的來源中學習,且每個來源往往只能監督部分身體部位;(3) 即時推論層面——人形全身動作 token 序列遠比機械臂長,純自迴歸解碼的延遲無法滿足真實世界全身控制所需的控制頻率。

- **Main method**:Holo-M 由三個核心組件構成。(1) **依身體部位分解的統一動作 tokenizer**:每個動作片段涵蓋 T=30 個時間步(30Hz 下 1 秒),依序拆成四組——末端執行器(EEF)、軀幹(body)、手(hand)、運動學(kinematics),對應維度分別為 48、29、14、5,總維度 A_t ∈ R^(30×96)。EEF 組包含雙臂腕部位置、6D 腕部旋轉、相機座標系下的指尖位置;body/hand 組是依硬體固定順序排列的關節空間目標;kinematics 組則是底盤速度、高度、偏航角速度指令。這種拆解讓每個異質資料來源(遙操作人形機器人、大規模第一人稱人類影片、模擬)只需監督它實際涵蓋到的身體部位,而不必強求每個來源都提供全身完整的 ground truth。(2) **FAST-RVQ 量化方案**:延續 FAST(沿時間軸做 DCT,再對量化後的 DCT 係數做 byte-pair encoding,得到變長序列——適合自迴歸解碼但不利於平行遮罩解碼)的精神,Holo-M 改為:僅保留每個動作維度前 N=2 個時間 DCT 係數作為「低頻」重建(透過對角投影矩陣 P_N),計算殘差 R_{g,N} = X_g − IDCT(P_N·DCT(X_g)),再對殘差獨立套用 Q=4 階殘差向量量化(Residual Vector Quantization,碼本以 k-means 擬合,不需神經網路 tokenizer)。這產生每組固定長度的 token 數 L_g = N·D_g + Q,四組分別為 (L_eef, L_body, L_hand, L_kin) = (100, 62, 32, 14),總計每個動作片段 208 個 token,驗證集重建誤差為 0.0068。固定長度的分組(相對於 FAST 的變長 BPE 輸出)對後續的平行遮罩擴散解碼至關重要。(3) **VLM 骨幹搭配動作 token 擴充詞彙表**:骨幹為 Qwen3-VL-2B,視覺輸入為當前頭部相機 RGB(640×360,機器人視角或人類第一人稱視角均可)。條件上下文 c_t 由視覺嵌入、任務指令、設定欄位(具身/資料來源字串,例如「來自 Humanoid Everyday 的 G1 人形機器人」或「來自 EgoDex 的人類第一人稱資料」)、量化後的狀態 token(關節角度裁剪至 [-π,π] 並均勻分箱為 256 個 token)拼接而成。動作 token 與語言共用同一個詞彙表/序列模型,不存在獨立連續動作專家那種需要與 VLM 骨幹做梯度隔離的「知識隔絕問題」。(4) **分組離散擴散解碼**:不對全部 208 個動作 token 做自迴歸生成(對即時全身控制而言太慢),而是在每個身體部位組內透過少量固定步數的去遮罩(離散擴散)平行解碼,但四組之間(EEF→body→hand→kinematics 順序)仍保持自迴歸,使得推論的實際耗時幾乎與動作 token 序列長度無關。(5) **四階段漸進式訓練管線**(第二張圖所示),涵蓋第一人稱人類影片(EgoDex)、人形遙操作(Humanoid Everyday)、模擬、目標任務微調四類異質資料,先訓練出一個聯合的「generalist」檢查點,再針對各任務做「specialist」微調。(6) **部署與控制迴圈**:真實機器人為配備雙 Dex3 靈巧手、頭頂 RealSense 相機的 Unitree G1-comp(競賽版),以 640×360/30Hz 輸入、31 維上半身關節角度為狀態(14 手 + 14 臂 + 腰部 roll/pitch/yaw;下半身/底盤速度/IMU 不作為輸入),於單張 RTX 5090 上透過 WebSocket 輸出 1 秒動作片段。沿用 Ψ0 的真實機器人部署棧(客戶端、觀測/動作協定、全身控制器),僅替換 policy server 以確保公平比較。採用「固定排程」:每 500ms(15 個 tick)取得新觀測;機器人在新動作片段推論期間繼續執行前一個片段,推論須在固定「保持」預算內完成(對應 2/4/8 個去遮罩步數分別為 233/333/500ms);若推論超時,機器人會回退至最後一個保持姿態。

- **和以往方式的差異**:與既有做法相比,Holo-M 最核心的設計選擇是徹底放棄為機械臂設計的單一扁平動作詞彙表,改用依身體部位劃分的 tokenizer 組合,讓異質資料來源各自貢獻它能提供的部分監督訊號,而非強求每筆資料都涵蓋全身自由度。另外,FAST-RVQ 相較原始 FAST 的關鍵差異在於產生固定長度而非變長的 token 序列,這個看似細節的改動實際上是平行遮罩擴散解碼得以成立的前提——若採用 FAST 原本的變長 BPE 輸出,無法直接套用分組平行解碼機制。更重要的是,動作 token 與語言 token 共用同一詞彙表/序列模型,避免了連續動作專家架構中「動作頭需要與 VLM 骨幹做梯度隔離」這一常見設計限制(作者稱為「知識隔絕問題」)。消融實驗顯示:即使拿掉分組擴散解碼、改回純自迴歸(「Holo-M AR」版本),模型依然打敗所有基線,說明 tokenizer 設計與聯合訓練配方才是主要增益來源,而分組擴散解碼則進一步帶來額外的準確度提升與大幅降低的延遲。

### Result

- **主要增強部分**:在 SIMPLE 人形 loco-manipulation benchmark(六項任務:XMovePick、BendPick、Handover、Mobile P&P、Grasp、XMoveBendPick,各三種域隨機化等級,每等級每任務 10 次 rollout,共 180 次/設定)上,generalist(單一多任務檢查點)設定下 Holo-M 總成績為 143/180;消融版本「Holo-M AR」(相同模型但改用自迴歸解碼而非分組擴散)為 138/180;次佳基線 Ψ0 為 114/180;π0.5 僅 28/180;DreamZero 為 38/180;ACT 為 79/180。值得注意的是,AR 消融版本本身就已經超越所有基線,說明 tokenizer 與聯合訓練配方才是主要增益來源,分組擴散解碼則在此之上再提供小幅準確度提升並大幅降低延遲。Specialist(逐任務微調)設定下,Holo-M 總成績為 163/180,對比最強基線 Ψ0 的 154/180;差距最大的任務是 Mobile P&P(最長 horizon、需要導航加操作複合的任務):Holo-M 25/30 對比 Ψ0 的 18/30,相對提升約 40%。預訓練資料消融(開迴圈 MAE / 閉迴圈成功率,滿分 180):無預訓練為 0.022 / 53;加入 Humanoid Everyday(HE)機器人資料為 0.020 / 119;再加入 EgoDex 人類影片為 0.019 / 138——即異質預訓練(機器人遙操作 + 人類第一人稱影片)讓閉迴圈成功率提升 2.6 倍(53→138/180)。真實世界推論延遲(每 30 步/1 秒片段,RTX 5090 上測得):2 個去遮罩步數為 175.8±11.5 ms;4 步為 275.7±9.3 ms;8 步為 476.8±16.9 ms。真實機器人部署(以每任務 100 筆遙操作片段微調的 specialist,各 10 次 rollout):Tabletop Grasp 成功率 10/10;Move Pick 成功率 8/10。

- **結果是否公正**:比較基線涵蓋 Ψ0、π0.5、DreamZero、ACT 四種代表性路線(連續 flow-matching 動作專家、WAM 式世界-動作聯合建模、傳統模仿學習架構),涵蓋面算是相對全面,且所有基線都在相同 SIMPLE benchmark、相同評測協定(generalist/specialist 雙軌)下比較。消融實驗(AR vs 分組擴散解碼)的設計清楚分離了 tokenizer/訓練配方與解碼機制各自的貢獻,是值得肯定的嚴謹性。但論文摘要與結果部分均未提及是否有與其他同樣採用離散動作 token、但應用於機械臂而非人形的既有 VLA(如 OpenVLA、RT-2 的離散化版本)做過比較,也沒有討論 FAST-RVQ 量化方案本身相較傳統 FAST 在重建誤差或下游任務上的直接消融對比,這使得「FAST-RVQ 改動本身的獨立貢獻」這一宣稱的驗證力度略顯不足。

### Limitation

- **已知 limitation**:作者明確指出本論文為「Holo-M v1」早期版本,並列出多個待解決方向:(1) 長 horizon、語言指定的任務推理尚未處理——未來版本可考慮將顯式推理 token(子任務分解、失敗恢復)與動作 token 交錯,而非擴大獨立動作專家規模;(2) 目前訓練資料(遙操作人形機器人 + EgoDex)規模相對有限,大幅擴充第一人稱人類影片規模被列為下一步自然方向;(3) Holo-M v1 使用解耦的全身控制器(WBC),未來版本計畫在保持 tokenization/解碼不變的前提下,將 detokenization 輸出重新映射至其他控制器(HoloMotion、SONIC)。此外,論文致謝部分提及圖 1-3 的繪製借助了 Claude(Anthropic)與 Codex(OpenAI)輔助,屬於透明度揭露而非科學限制。

- **從 result 來看的弱項**:論文並未提供機械臂場景(而非人形)下 FAST-RVQ 與原始 FAST 的直接對照消融,使得「固定長度量化對平行解碼的必要性」這一核心宣稱,雖邏輯合理,但缺乏獨立於人形場景之外的通用性驗證。此外,真實機器人部署僅驗證了兩項任務(Tabletop Grasp、Move Pick),樣本量偏小,距離充分驗證真實世界穩健性仍有差距。

### Related work

- Holo-M 與本頁「Architecture Paradigms」主題下已收錄的多篇離散/連續動作解碼論文(如 Discrete Diffusion VLA、DFM-VLA、SnapFlow)屬於同一設計光譜的不同取捨——Discrete Diffusion VLA 將離散擴散套用於統一 vision/language/action 解碼,Holo-M 則專門針對人形全身控制的異質動作空間設計了分組 tokenizer 與分組擴散解碼,兩者在「離散 token + 擴散式解碼」的交集上可互相參照。Holo-M 也與「Embodiment Diversity」主題下的 WholeBodyVLA、HAF、LeVERB 等人形全身控制論文形成直接對比——這些論文多聚焦於 latent action vocabulary 或 RL controller,Holo-M 則是首個將動作 token 直接併入語言模型詞彙表的全身人形方案。其消融比較對象涵蓋 Ψ0、π0.5、DreamZero、ACT,其中 DreamZero(WAM 式世界-動作聯合建模)已收錄於本頁姊妹頁 World Model Papers,顯示 Holo-M 在評測設計上有意識地涵蓋了 WAM 路線作為對照。
- 判斷值得 survey 的程度:高。Holo-M 是少數針對「人形全身(而非機械臂)離散 token 化」這一具體工程瓶頸提出完整解法並有真實機器人驗證的論文,其 FAST-RVQ 量化方案與分組擴散解碼的組合設計具有可遷移性,適合與本頁「Architecture Paradigms」及「Embodiment Diversity」主題交叉參照。

### Conclusion

- **綜合評價**:Holo-M 針對人形全身 loco-manipulation 的離散動作 token 化提出了一套系統性且經過消融驗證的解法,其核心洞見——依身體部位拆解 tokenizer、固定長度量化、分組而非全域自迴歸解碼——分別解決了 tokenization、訓練資料異質性、即時推論三個複合瓶頸。消融實驗清楚顯示 AR 版本本身已能超越所有基線,证明了 tokenizer 與訓練配方設計本身的價值,而分組擴散解碼則是錦上添花的效率優化,這種分層驗證的實驗設計增加了論文的可信度。作為來自 Horizon Robotics(地平線機器人,中國自動駕駛晶片與機器人領域的重要產業參與者)的工業界論文,其結果直接服務於人形機器人全身控制的實際部署需求。

- **與其他重要文章的關係**:Holo-M 與本頁姊妹頁 World Model Papers 中的 DreamZero(WAM 範式)形成直接對比基線,顯示離散 token VLA 與世界-動作聯合建模在人形全身控制任務上的競爭關係,值得與 τ0-WM、τ0-VLA 等本頁已收錄的統一影片-動作模型對照閱讀。ROCm/AMD 在此領域尚待補強之處:Holo-M 的訓練管線涉及 Qwen3-VL-2B 骨幹上的大規模異質資料(遙操作、第一人稱影片、模擬)聯合訓練,以及分組離散擴散解碼在推論時的即時性要求(233-500ms 延遲預算內完成去遮罩),這類「VLM 骨幹 + 離散動作 token 擴散解碼」的混合計算模式目前預設在 NVIDIA GPU 生態(PyTorch + CUDA + RTX 5090 級別硬體)上執行;隨著人形機器人全身控制逐漸從機械臂範式轉向更複雜的多部位協同控制,驗證 ROCm 平台在「VLM 骨幹推論 + 多步去遮罩擴散解碼」這類混合延遲敏感工作負載下的吞吐量與即時性表現,將是值得關注的生態系拓展方向。
