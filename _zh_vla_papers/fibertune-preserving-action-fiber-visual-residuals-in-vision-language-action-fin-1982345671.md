### Abstract

以動作標籤監督的 VLA 微調能有效擬合示範資料，但這種監督只約束會改變預測動作的特徵方向；在「動作等價」狀態間保持一致的視覺結構（物件顏色、類別、背景、干擾物、與任務相關的未來狀態線索等）完全得不到梯度訊號，因而可能在微調過程中被壓縮甚至坍縮——即便這些資訊可能對泛化至關重要（例如泛化到未見過的物件顏色）。作者將此現象形式化為沿「動作纖維」（action fiber，即動作等價的狀態集合）的「殘餘視覺坍縮」，並提出 FiberTune：一個訓練時的輔助目標，能在不增加推論時開銷的前提下保留教師模型結構化的視覺殘餘。FiberTune 以線上訓練的動作探針（action probe）估計動作可預測的特徵方向，將其從中間視覺 token 表示中濾除，再將濾除後的殘餘與凍結視覺教師模型對齊，同時正規化其有效秩（effective rank）。在涵蓋兩個 benchmark、兩種架構（π0.5 與 OpenVLA-OFT）的六種受控模擬情境，以及真實世界 SO-101 pick-place 任務中，FiberTune 在所有情境下均優於僅用任務損失微調的基線；代表性增益包括長 horizon CALVIN ABC→D 上 SR(5) 提升 10.7 個百分點，以及真實 SO-101 任務成功率從 72.7% 提升至 78.1%。已被 CoRL 2026 接受。

### Method

- **要解決的問題**：VLA 微調時的動作監督損失，只對「會改變預測動作」的特徵方向施加約束；而在多個「動作等價」狀態間保持一致的視覺資訊（例如背景、物件顏色類別、干擾物、與任務相關但當下不影響動作的未來狀態線索）完全不會收到任何一階梯度訊號。先前研究已觀察到 VLA 微調會使繼承自預訓練的視覺表徵退化，但尚未明確指出「退化後應保留哪些視覺結構」，這正是 FiberTune 想填補的空白。

- **Main method**：核心概念是將視覺 token 表示 R_θ(v,ℓ) 透過局部預測頭 h_θ 映射到動作目標 a，並在池化特徵 R̄_θ 附近做線性化得到 Jacobian J_θ；落在 J_θ 列空間（Row space）中的方向會一階地改變動作（受任務損失約束），而落在零空間（Null space）中的方向則是「與動作纖維相切」——也就是動作等價、卻得不到一階梯度訊號的方向。作者將此形式化為資訊論目標：在任務損失不超過 ε 的前提下，最大化零空間投影 U_θ 與凍結視覺教師模型的中心化 token 表示 Z_c 之間的條件互信息 I(U_θ; Z_c | A, L)。透過鏈式法則展開後可得兩項：(a) 條件熵 H(U_θ|A,L)——鼓勵殘餘保持高秩、不坍縮；(b) H(U_θ|Z_c,A,L)——鼓勵殘餘可被教師模型結構所預測/對齊。由於精確計算 Jacobian 零空間並不實際，FiberTune 改用一個輕量的線上線性動作探針（從 stop-gradient 池化視覺特徵回歸至動作向量）來近似動作可預測方向的列空間 P_probe，並取其互補濾波器 R_pf = R_θ(I − P_probe) 作為「探針濾除後的殘餘」；探針本身僅透過自身回歸損失訓練，其餘輔助損失的梯度則經由 R_pf 回傳至 R_θ（訓練策略更新時將 P_probe 視為固定）。接著以兩個輔助損失實現該目標：(1) 教師條件化殘餘對齊——凍結視覺教師 τ 產出 Z=τ(V)，透過一個固定的隨機初始化逐 token MLP adapter g 將 R_pf 映射至教師空間，兩者皆先做 token 中心化與 L2 正規化後以 cosine loss 對齊（僅在匹配的視覺 token 範圍內計算，排除語言與動作 token）；(2) 有效秩殘餘先驗——計算探針濾除後殘餘（adapter 之前）的批次 token 協方差特徵值 {λ_i}，正規化為機率分布後計算正規化頻譜（Shannon）熵 H_shape，並以其負值作為秩損失 L_rank=−H_shape，鼓勵殘餘能量分散於多個方向而非集中於少數與教師相關的方向。最終訓練目標為 L = L_task + λ_align·L_align + λ_rank·L_rank；部署時教師模型、探針與 adapter 全數移除，不產生任何推論時開銷。

- **和以往方式的差異**：與最相近的先前工作 BlindVLA（將完整隱藏狀態直接對齊至凍結教師）不同，FiberTune 僅對「探針濾除後的殘餘」做對齊，而非對整個視覺狀態做監督；消融實驗顯示，若對完整 token 做對齊（不濾除動作可預測方向）反而會傷害效能（CALVIN 上 SR(5) 從基線 61.4% 降至 58.3%），證實了「先濾除動作方向、再對齊殘餘」這個設計選擇的必要性，而非既有教師對齊技巧的直接套用。

### Result

- **主要增強部分**：在六種受控微調情境（CALVIN ABC→D 與 LIBERO，各自搭配 π0.5 與 OpenVLA-OFT 的 general/adapted checkpoint）上，FiberTune 全面優於僅用任務損失的基線：CALVIN ABC→D（π0.5, adapted）SR(5) 從 61.4% 提升至 72.1%（+10.7 個百分點），平均序列長度從 3.837 提升至 4.116；LIBERO（π0.5, general）SR 從 92.35% 提升至 93.35%；LIBERO（OpenVLA-OFT, general）SR 從 42.50% 提升至 48.95%（+6.45，最大增幅）。真實世界 SO-101 pick-place（128 次試驗）任務成功率從 72.7% 提升至 78.1%，其中分佈外綠色方塊（未見顏色，n=32）成功率從 46.9% 大幅提升至 62.5%（+15.6 個百分點，作者稱因樣本量小屬「提示性」證據）。表徵診斷指標（殘餘 CKA、殘餘有效秩）在全部六種情境下皆一致提升，例如 CALVIN/π0.5/adapted 的 CKA 從 0.202 升至 0.467、有效秩從 8.35 升至 58.84。

- **結果是否公正**：消融實驗（Table 4）系統性拆解了兩個輔助損失的個別與聯合貢獻：僅做完整 token 對齊反而傷害效能（3.685/58.3%，低於基線）；僅做殘餘秩損失單獨即帶來明顯提升（4.064/70.5%，是單一成分中貢獻最大者）；兩者聯合的完整 FiberTune 達到最佳效果（4.116/72.1%）。此設計清楚顯示效益並非單純來自教師監督，而是與「保持殘餘分散」密切相關。論文在兩種不同架構（π0.5 為 flow-matching 動作頭、OpenVLA-OFT 為自迴歸動作頭）與模擬+真實雙軌上均一致驗證，具備合理嚴謹度，並提供專案網站（fibertune.github.io）供查閱。

### Limitation

- **已知 limitation**：作者明確指出，FiberTune 引入額外訓練時運算開銷（凍結教師、線上探針、輔助損失），雖然推論不受影響；探針濾除後的殘餘僅是對真實「動作纖維殘餘」的一階、池化特徵近似，當動作預測高度非線性或視覺 token 貢獻高度異質時可能失準；輔助損失與任務損失的相對權重需針對各 benchmark 個別以短期校準實驗調整，尚未有自動平衡機制（留待未來工作）。

- **從 result 來看的弱項**：真實機器人驗證僅限單一任務與單一機械手臂平台（SO-101），且分佈外顏色測試樣本量僅 32 次試驗，論文自陳結果僅屬「提示性」而非決定性證據；更多樣真實世界條件下的失效模式尚未被充分刻畫。

### Related work

- FiberTune 與本頁已收錄的 VLA policy 家族（RT-2、OpenVLA、π0 系列）及既有微調範式高度相關，其消融比較對象涵蓋 ACT、Diffusion Policy 等動作監督式模仿學習方法；最直接的先行工作是 BlindVLA（將完整隱藏狀態對齊至凍結教師），FiberTune 的改良在於改為對齊「探針濾除後的殘餘」而非完整狀態。此外亦與 MAPS（模組化漸進式視覺-語言保留排程）、Spatial Forcing（將 VLA 特徵對齊至空間基礎表示）、RS-CL（機器人狀態感知對比正規化）等既有視覺表徵保留技巧互補，並援引 VICReg 風格的變異數/協方差反坍縮正規化與 CKA、有效秩/participation ratio 等表徵診斷工具作為分析基礎。
- 判斷值得 survey 的程度：中高。FiberTune 提出的「先以動作探針濾除動作方向、再對殘餘做教師對齊與秩正則化」框架具有跨架構（自迴歸、flow-matching）可遷移性，且已在模擬與真實雙軌驗證，並開源專案頁面，適合與本頁「Interpretability & Diagnostics」及既有教師對齊技巧交叉參照。

### Conclusion

- **綜合評價**：FiberTune 精準地指出了 VLA 微調中一個此前未被充分形式化的問題——動作監督僅覆蓋一部分特徵空間，導致「動作等價」但可能攸關泛化的視覺結構被悄悄坍縮；其解法設計簡潔（訓練時輔助損失、推論時零開銷），並透過資訊論框架與紮實的消融實驗證明增益來源，是一篇方法論貢獻扎實的 CoRL 2026 論文，對任何在生產環境中對 VLA 基礎模型做任務專屬微調的團隊都有直接參考價值。

- **與其他重要文章的關係**：FiberTune 與本頁「Interpretability & Diagnostics」主題下的 Sparse Autoencoders、Not All Features Are Created Equal、Artificial Foveated Perception（AFP，本頁已收錄之 CoRL 2026 論文）共享「診斷並修正 VLA 微調期間視覺表徵退化」的核心關懷；與 AFP 相比，AFP 監督「policy 依賴哪些視覺區域」，FiberTune 則監督「動作等價方向上的視覺結構是否保留」，兩者互補且都是訓練時介入、推論時零開銷的設計哲學。ROCm/AMD 在此領域尚待補強之處：FiberTune 的線上動作探針、frozen teacher 對齊與批次協方差特徵值分解等運算目前皆以 NVIDIA GPU 生態（PyTorch + CUDA）為預設環境，尚未見到針對 ROCm 的特徵值分解或線上探針訓練效能基準測試；由於這類訓練時輔助模組的運算量相對主幹網路而言較輕量，若 AMD 欲切入機器人基礎模型微調的訓練基礎設施市場，驗證此類輕量輔助訓練流程在 ROCm 上的數值穩定性與吞吐量，會是相對低成本的生態系拓展切入點。
